# VEXORA

A free, responsive HTML5 browser games portal.

The site is built as a lightweight static website and prepared for deployment on Cloudflare Pages.

## Hosting
Production source: `main` branch on GitHub, deployed through Cloudflare Pages.

## Local preview
Open `index.html` in a browser.


## Game catalogue
The homepage reads the verified game list from `games/games.json` and renders it with `assets/js/games.js`. Only games reviewed and approved for this project should be added to that catalogue.
