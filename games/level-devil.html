HOW TO PLAY

Game instructions

Use A and D or the Left and Right Arrow keys to move. Press W, the Up Arrow or Spacebar to jump. On mobile, use the on-screen movement and jump buttons. Watch the platforms carefully and reach the exit door without hitting traps.

ABOUT THIS GAME

About the game

Level Devil is a fast-paced 2D platform game where every stage can hide an unexpected trap. Run, jump and react quickly as floors disappear, spikes move and familiar routes suddenly change. The game also includes a competitive two-player mode. This VEXORA page introduces the game and links to its original browser listing on Poki.

GAME SOURCE & ATTRIBUTION

Level Devil was created by Adam Corey, known as Unept. Official browser game listing: Poki.
