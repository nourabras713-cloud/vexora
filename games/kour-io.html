Controls

W / A / S / D or arrow keys: move. Mouse: aim and shoot. Space: jump. R: reload. Shift or C: crouch. B: emote. F: inspect weapon. 1, 2, 3: switch weapons. Mobile and tablet players can use the on-screen touch controls.

COMPLETE GAME GUIDE

Kour.io – Complete Multiplayer FPS Guide

Kour.io is a browser-based multiplayer first-person shooter built around quick matches, responsive movement and a playful block-style visual design. Developed by Legion Platforms, the game lets players enter online arenas, choose a character class and compete using different weapons. It is available through its official website and supports desktop as well as mobile play.

Choose a class that fits your style

Different classes offer different approaches to combat. Some are suited to close-range encounters, while others work better when holding longer sightlines or supporting teammates. Try more than one class before settling on a favourite. A weapon that feels powerful in a small indoor area may be less effective across an open map, so adapt your choice to the match and your preferred distance.

Explore the game modes

Kour.io offers several ways to compete. Free For All puts every player against everyone else, making awareness and survival essential. Team Deathmatch rewards cooperation and coordinated pressure. Gun Game challenges players to progress through a weapon sequence, while Hardpoint focuses on controlling an objective area. Other modes and community experiences may also appear as the game evolves.

Maps, movement and positioning

Learning the layout of each arena can improve your performance. Notice where opponents tend to appear, which routes provide cover and where open sightlines create danger. Keep moving instead of remaining in one predictable position. Jumping, crouching and using the environment intelligently can make you harder to track. The game's movement mechanics also reward practice, so take time to learn how your chosen class handles.

How to play Kour.io

  1. Open the official Kour.io website using the Play Now button above.
  2. Wait for the game to load and choose your character or class.
  3. Select an available game mode or join a server.
  4. Use the keyboard and mouse on desktop, or the touch controls on a supported mobile device.
  5. Complete match objectives, improve your aim and experiment with different classes.

Desktop and mobile controls

Desktop controls commonly use WASD or the arrow keys for movement, the mouse for aiming and shooting, Space to jump, R to reload, and Shift or C to crouch. Number keys can switch weapons. Mobile and tablet players can use the on-screen controls. Button layouts and key assignments can change with updates, so check the game's own help or settings screen if something differs.

Progression and customization

Matches and missions can award in-game points and experience. These rewards may be used for cosmetic items, crates, characters or other customization options, depending on the current version. Focus on learning the maps and improving your match performance; progression will follow as you play. Optional purchases and game features can change, so review the official game interface for current details.
