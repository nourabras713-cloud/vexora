HOW TO PLAY

Game instructions

Use the Arrow Keys on a computer or swipe in any direction on a touchscreen to move all tiles. Matching tiles merge when they collide. Each valid move adds a new tile to the board. Keep combining numbers, plan your moves and try to reach 2048 before the board fills up.

ABOUT THIS GAME

About 2048

2048 is a classic single-player number puzzle. Slide numbered tiles around the 4×4 board; when two tiles with the same value touch, they merge into one tile with their values added together. Each move can create a new tile, so plan ahead and keep enough open space to continue. Your goal is to build a tile worth 2048. This VEXORA page links to the original classic 2048 game, where you can play in your browser.
