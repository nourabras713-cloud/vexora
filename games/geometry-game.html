HOW TO PLAY

Game instructions

Tap the screen, click, or press the action key to jump over obstacles. Time your jumps carefully; hitting an obstacle sends you back to the beginning.

ABOUT THIS GAME

About the game

Geometry Game is a rhythm-inspired side-scrolling platform challenge. Time each jump to clear obstacles, keep moving with the beat and restart quickly when a run ends. Its simple one-button design is easy to understand but takes practice to master. Play Now opens the original CrazyGames game page.
